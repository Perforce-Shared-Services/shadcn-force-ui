## Usage

```vue showLineNumbers
<script setup lang="ts">
import { Bubble, BubbleContent } from "@/components/ui/bubble"
import { Message, MessageAvatar, MessageContent } from "@/components/ui/message"
</script>

<template>
  <Message align="end">
    <MessageAvatar />
    <MessageContent>
      <Bubble>
        <BubbleContent>Deploying to prod real quick.</BubbleContent>
      </Bubble>
    </MessageContent>
  </Message>
</template>
```

## Composition

Use the following composition to build a message:

```text
Message
├── MessageAvatar
└── MessageContent
    ├── Bubble
    ├── MessageHeader
    └── MessageFooter
```

Wrap consecutive messages in `MessageGroup`:

```text
MessageGroup
├── Message
└── Message
```

## Features

- Start and end alignment with automatic layout mirroring
- Avatar slot pinned to the bottom of the row
- Header and footer slots for names, timestamps, and actions
- Composes Bubble, Attachment, and Marker
- Customizable styling through the `class` prop on every part

## Accessibility

### Label icon-only actions

Action buttons in `MessageFooter` must carry `aria-label` (and ideally `title`) so their purpose is announced:

```vue showLineNumbers
<Button variant="ghost" size="icon" aria-label="Copy" title="Copy">
  <CopyIcon />
</Button>
```

### Status updates

For typing or streaming indicators, use `Marker` with `role="status"` inside the thread rather than a bare text node, so updates are announced as they appear.

## API Reference

### Message

The root conversation row. Set `data-align` on children for alignment-aware styling.

| Prop    | Type               | Default   | Description                                      |
| ------- | ------------------ | --------- | ------------------------------------------------ |
| `align` | `"start" \| "end"` | `"start"` | The side of the row the sender is aligned to.    |
| `class` | `string`           | -         | Additional classes to apply to the root element. |

### MessageGroup

Groups consecutive messages in a thread.

| Prop    | Type     | Default | Description                                    |
| ------- | -------- | ------- | ---------------------------------------------- |
| `class` | `string` | -       | Additional classes to apply to the group root. |

### MessageAvatar

A rounded avatar slot pinned to the bottom of the row.

| Prop    | Type     | Default | Description                                     |
| ------- | -------- | ------- | ----------------------------------------------- |
| `class` | `string` | -       | Additional classes to apply to the avatar slot. |

### MessageContent

The message body column. Bubbles, headers, footers, and attachments go here.

| Prop    | Type     | Default | Description                                        |
| ------- | -------- | ------- | -------------------------------------------------- |
| `class` | `string` | -       | Additional classes to apply to the content column. |

### MessageHeader

Metadata shown above the bubble, e.g. the sender name.

| Prop    | Type     | Default | Description                                |
| ------- | -------- | ------- | ------------------------------------------ |
| `class` | `string` | -       | Additional classes to apply to the header. |

### MessageFooter

Metadata shown below the bubble, e.g. timestamps, delivery state, or actions.

| Prop    | Type     | Default | Description                                |
| ------- | -------- | ------- | ------------------------------------------ |
| `class` | `string` | -       | Additional classes to apply to the footer. |
