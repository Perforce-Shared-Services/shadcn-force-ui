The `DirectionProvider` component is used to set the text direction (`ltr` or `rtl`) for your application. This is essential for supporting right-to-left languages like Arabic, Hebrew, and Persian.


## useDirection

The `useDirection` composable is used to get the current direction of the application.

```ts showLineNumbers
import { useDirection } from "@/components/ui/direction"

const direction = useDirection()
```

## API Reference

### DirectionProvider

Wraps your app to provide the text direction to all Reka UI primitives. Accepts both `dir` (Reka UI naming) and `direction` (alias matching the React port).

| Prop        | Type             | Default | Description                                      |
| ----------- | ---------------- | ------- | ------------------------------------------------ |
| `dir`       | `"ltr" \| "rtl"` | -       | The text direction.                              |
| `direction` | `"ltr" \| "rtl"` | -       | Alias for `dir`. Takes precedence when both set. |

### useDirection

Returns the current direction from the nearest `DirectionProvider` (defaults to `"ltr"`).
