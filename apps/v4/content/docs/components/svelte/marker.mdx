## Usage

```svelte
<script lang="ts">
  import { Marker, MarkerContent, MarkerIcon } from "@/svelte-ui/marker/index.js";
</script>
```

```svelte
<Marker>
  <MarkerIcon><GitBranchIcon /></MarkerIcon>
  <MarkerContent>Switched to a new branch</MarkerContent>
</Marker>
```

## API Reference

### Marker

The root marker row.

| Prop      | Type                                   | Default     |
| --------- | -------------------------------------- | ----------- |
| `variant` | `"default" \| "separator" \| "border"` | `"default"` |
| `class`   | `string`                               | -           |

### MarkerIcon

A leading icon slot. Hidden from assistive tech.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### MarkerContent

The marker text. Use the `shimmer` class for loading states.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |
