The `Message` component composes a full chat turn: avatar, content bubbles, header, and footer. It works together with the [`Bubble`](/docs/components/svelte/bubble) and [`Attachment`](/docs/components/svelte/attachment) components.

## Usage

```svelte
<script lang="ts">
  import {
    Message,
    MessageAvatar,
    MessageContent,
  } from "@/svelte-ui/message/index.js";
  import { Bubble, BubbleContent } from "@/svelte-ui/bubble/index.js";
</script>
```

```svelte
<Message align="end">
  <MessageAvatar>
    <Avatar.Root>...</Avatar.Root>
  </MessageAvatar>
  <MessageContent>
    <Bubble>
      <BubbleContent>Deploying to prod real quick.</BubbleContent>
    </Bubble>
  </MessageContent>
</Message>
```

## API Reference

### Message

The root message row. Use `align` to switch sides.

| Prop    | Type               | Default   |
| ------- | ------------------ | --------- |
| `align` | `"start" \| "end"` | `"start"` |
| `class` | `string`           | -         |

### MessageGroup

Groups consecutive messages. Applies tighter spacing between members.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### MessageAvatar

A circular media slot anchored to the bubble edge.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### MessageContent

The message body column holding bubbles, attachments, header, and footer.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### MessageHeader

Optional sender/meta line above the content.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### MessageFooter

Optional status/actions line below the content. Right-aligned on end-aligned messages.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |
