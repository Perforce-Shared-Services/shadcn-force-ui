The `DirectionProvider` component sets `dir` on its subtree and provides the direction to descendant components that support RTL, mirroring React's `DirectionProvider`.

## Usage

```gts showLineNumbers
import { DirectionProvider } from '@/ui/direction';
```

```hbs showLineNumbers
<DirectionProvider @direction="rtl">
  <DropdownMenu>
    ...
  </DropdownMenu>
</DirectionProvider>
```

## Notes

- `@direction` defaults to `"ltr"`.
- The provider renders a `div` with the matching `dir` attribute so CSS logical properties resolve correctly.
- Descendant components can consume the `direction-context` key via `ember-provide-consume-context` for programmatic access.

## API Reference

### DirectionProvider

| Prop         | Type             | Default | Description                                         |
| ------------ | ---------------- | ------- | --------------------------------------------------- |
| `@direction` | `"ltr" \| "rtl"` | `"ltr"` | Text direction applied to the subtree.              |
| `@class`     | `string`         | -       | Additional classes to apply to the wrapper element. |
