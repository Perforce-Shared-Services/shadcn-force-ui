The `MessageScroller` component pins a chat thread to the newest message as content arrives, backs off when the reader scrolls up, and shows a button to jump back to the end.

## Usage

```gts showLineNumbers
import {
  MessageScroller,
  MessageScrollerButton,
  MessageScrollerContent,
  MessageScrollerItem,
  MessageScrollerViewport,
} from '@/ui/message-scroller';
```

```hbs showLineNumbers
<MessageScroller>
  <MessageScrollerViewport>
    <MessageScrollerContent>
      {{#each this.messages as |message|}}
        <MessageScrollerItem>...</MessageScrollerItem>
      {{/each}}
    </MessageScrollerContent>
  </MessageScrollerViewport>
  <MessageScrollerButton />
</MessageScroller>
```

## Behavior

- **Auto-scroll** (default on): the viewport jumps to the bottom on mount and whenever content grows while already at the end.
- **Back-off**: scrolling away from the end disables auto-scroll until the reader returns.
- **Jump-to-latest**: `MessageScrollerButton` appears when the target edge is out of view. Use `@direction="start"` for a jump-to-start button.

Disable auto-scroll by passing `@autoScroll={{false}}` to `MessageScroller`.

## API Reference

### MessageScroller

Root component owning scroll state.

| Prop          | Type      | Default | Description                                              |
| ------------- | --------- | ------- | -------------------------------------------------------- |
| `@autoScroll` | `boolean` | `true`  | Pin to the newest content on mount and while at the end. |

### MessageScrollerViewport

The overflow container. Tracks scroll position and reports it to the root.

### MessageScrollerContent

Column layout wrapper for the items.

### MessageScrollerItem

Wrapper for a single message. Uses `content-visibility: auto` to skip rendering work for off-screen messages.

### MessageScrollerButton

Jump button shown only when its target edge is out of view.

| Prop         | Type               | Default | Description                        |
| ------------ | ------------------ | ------- | ---------------------------------- |
| `@direction` | `"start" \| "end"` | `"end"` | Which edge this button scrolls to. |
| `@class`     | `string`           | -       | Additional classes to apply.       |
