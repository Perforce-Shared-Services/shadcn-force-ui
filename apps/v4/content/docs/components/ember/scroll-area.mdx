## API Reference

### ScrollArea

The scroll container root. Size it with utility classes (e.g. `class="h-72 w-48"`).

| Prop     | Type     | Default | Description                                      |
| -------- | -------- | ------- | ------------------------------------------------ |
| `@class` | `string` | -       | Additional classes to apply to the root element. |

### ScrollBar

The custom scrollbar. A vertical scrollbar is included by default; add a horizontal one explicitly.

| Prop           | Type                         | Default      | Description                  |
| -------------- | ---------------------------- | ------------ | ---------------------------- |
| `@orientation` | `"vertical" \| "horizontal"` | `"vertical"` | Axis of the scrollbar.       |
| `@class`       | `string`                     | -            | Additional classes to apply. |
