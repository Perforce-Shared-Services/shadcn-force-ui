The `Message` component lays out a conversation turn: avatar on the outside, content (bubbles, attachments) on the inside, plus optional header and footer rows. Use `MessageGroup` for grouped turns.

## Usage

```gts showLineNumbers
import { Message, MessageAvatar, MessageContent } from '@/ui/message';
```

```hbs showLineNumbers
<Message @align="end">
  <MessageAvatar>
    <Avatar>
      <AvatarImage alt="@me" src="..." />
    </Avatar>
  </MessageAvatar>
  <MessageContent>
    <Bubble><BubbleContent>Hello!</BubbleContent></Bubble>
  </MessageContent>
</Message>
```

## Avatar

`MessageAvatar` holds an [`Avatar`](/docs/components/ember/avatar). Without a child it renders an empty muted circle.

<ComponentPreview framework="ember" name="message-avatar" />

## Header and Footer

`MessageHeader` names the sender; `MessageFooter` carries delivery state or actions. Footers align to the end automatically on end-aligned messages.

## API Reference

### Message

The message row container.

| Prop     | Type               | Default   | Description                                      |
| -------- | ------------------ | --------- | ------------------------------------------------ |
| `@align` | `"start" \| "end"` | `"start"` | Which side of the thread the message sits on.    |
| `@class` | `string`           | -         | Additional classes to apply to the root element. |

### MessageAvatar

Holds the sender's avatar.

| Prop     | Type     | Default | Description                                      |
| -------- | -------- | ------- | ------------------------------------------------ |
| `@class` | `string` | -       | Additional classes to apply to the avatar frame. |

### MessageContent

Column that holds bubbles, attachments, header, and footer.

| Prop     | Type     | Default | Description                                      |
| -------- | -------- | ------- | ------------------------------------------------ |
| `@class` | `string` | -       | Additional classes to apply to the content slot. |

### MessageHeader

Optional row above the content, typically the sender's name.

| Prop     | Type     | Default | Description                  |
| -------- | -------- | ------- | ---------------------------- |
| `@class` | `string` | -       | Additional classes to apply. |

### MessageFooter

Optional row below the content, typically delivery status or actions. Justifies to the end on end-aligned messages.

| Prop     | Type     | Default | Description                  |
| -------- | -------- | ------- | ---------------------------- |
| `@class` | `string` | -       | Additional classes to apply. |

### MessageGroup

Groups consecutive messages in a thread.

| Prop     | Type     | Default | Description                  |
| -------- | -------- | ------- | ---------------------------- |
| `@class` | `string` | -       | Additional classes to apply. |
