## Usage

```ts showLineNumbers
import {
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogPortal,
  DialogRoot,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog"
```

```html showLineNumbers
<div uiDialogRoot>
  <button uiButton variant="outline" uiDialogTrigger type="button">Open</button>
  <ng-template uiDialogPortal>
    <div uiDialogOverlay></div>
    <div uiDialogContent class="sm:max-w-sm">
      <div uiDialogHeader>
        <h2 uiDialogTitle>Edit profile</h2>
        <p uiDialogDescription>Make changes to your profile.</p>
      </div>
      <div uiDialogFooter>
        <button uiButton variant="outline" type="button" uiDialogClose>Cancel</button>
      </div>
    </div>
  </ng-template>
</div>
```

Every part is an attribute selector on a native element, so the host keeps its
native semantics — Angular's idiomatic equivalent of React's `asChild`/`render`.

## Composition

Use the following composition to build a `Dialog`:

```text
DialogRoot
├── DialogTrigger
└── DialogPortal (ng-template)
    ├── DialogOverlay
    └── DialogContent
        ├── DialogHeader
        │   ├── DialogTitle
        │   └── DialogDescription
        └── DialogFooter
            └── DialogClose
```
