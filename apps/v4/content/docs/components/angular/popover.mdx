## Usage

```ts showLineNumbers
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverPortal,
  PopoverPositioner,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover"
```

```html showLineNumbers
<div uiPopover>
  <button uiButton variant="outline" uiPopoverTrigger type="button">
    Open Popover
  </button>
  <ng-template uiPopoverPortal>
    <div uiPopoverPositioner side="bottom" align="center" [sideOffset]="4">
      <div uiPopoverContent>
        <div uiPopoverHeader>
          <div uiPopoverTitle>Title</div>
          <p uiPopoverDescription>Description text here.</p>
        </div>
      </div>
    </div>
  </ng-template>
</div>
```

Every part is an attribute selector on a native element (or an `ng-template`
for the portal), so the host keeps its native semantics — Angular's idiomatic
equivalent of React's `asChild`/`render`.

React's `PopoverContent` folds Portal + positioning + styling into one
component; radix-ng v1.x splits it into three nodes. Positioning inputs
(`side`, `align`, `sideOffset`, `alignOffset`, `dir`) go on
`[uiPopoverPositioner]`; visual classes go on `[uiPopoverContent]`.

## Composition

Use the following composition to build a `Popover`:

```text
Popover
├── PopoverTrigger
└── PopoverPortal (ng-template)
    └── PopoverPositioner
        └── PopoverContent
            ├── PopoverHeader
            │   ├── PopoverTitle
            │   └── PopoverDescription
            └── …content
```
