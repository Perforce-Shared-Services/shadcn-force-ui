## Usage

```ts
import { SpinnerComponent } from "@/components/ui/spinner"
```

```html
<span uiSpinner></span>
<span uiSpinner color="primary" size="lg"></span>
```

The spinner is `aria-hidden` — it is purely visual. The container owns the loading state via `aria-busy="true"` + an `aria-live` region.

The `animate-spinner` animation (500ms) requires this in your `tailwind.css`:

```css
@theme {
  --animate-spinner: spin 500ms linear infinite;
}
```
