## Usage

```ts
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert"
```

```html
<div uiAlert variant="warning">
  <div uiAlertTitle>Heads up</div>
  <div uiAlertDescription>Something happened.</div>
</div>
```

## API Reference

### AlertComponent

| Input     | Type                                                                        | Default     |
| --------- | --------------------------------------------------------------------------- | ----------- |
| `variant` | `"default" \| "destructive" \| "warning" \| "success" \| "info"`            | `"default"` |
| `icon`    | `"auto" \| "none" \| "info" \| "warning" \| "success" \| "error" \| "bell"` | `"auto"`    |
| `role`    | `"auto" \| "alert" \| "status"`                                             | `"auto"`    |
| `class`   | `string`                                                                    | –           |
