## Usage

```ts
import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar"
```

```html
<span uiAvatar>
  <img uiAvatarImage src="..." alt="Ada Lovelace" />
  <span uiAvatarFallback>AL</span>
</span>
```

`AvatarImage` tracks load/error events and updates a shared signal. `AvatarFallback` is shown while the image hasn't loaded.
