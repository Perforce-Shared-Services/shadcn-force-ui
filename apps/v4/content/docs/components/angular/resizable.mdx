## Usage

```ts
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@/components/ui/resizable"
```

```html
<div uiResizablePanelGroup direction="horizontal">
  <div uiResizablePanel [defaultSize]="50">One</div>
  <div uiResizableHandle></div>
  <div uiResizablePanel [defaultSize]="50">Two</div>
</div>
```

Host the parts on native elements — `[uiResizablePanelGroup]` on a container `div`, `[uiResizablePanel]` on each panel element, and `[uiResizableHandle]` on the divider element. The handle renders `role="separator"` with full keyboard support (arrow keys, Home/End, Escape to cancel a drag).

## Composition

Use the following composition to build a `ResizablePanelGroup`:

```text
ResizablePanelGroup
├── ResizablePanel
├── ResizableHandle
└── ResizablePanel
```

## API Reference

The Angular resizable is hand-rolled — no Angular primitive exists for a
splitter (behavioural reference:
[react-resizable-panels](https://github.com/bvaughn/react-resizable-panels/tree/main/packages/react-resizable-panels)).
Inputs added by Force UI:

### ResizablePanelGroup

Attribute selector: `[uiResizablePanelGroup]`.

| Input       | Type                            | Default        |
| ----------- | ------------------------------- | -------------- |
| `direction` | `"horizontal" \| "vertical"`    | `"horizontal"` |

### ResizablePanel

Attribute selector: `[uiResizablePanel]`. Sizes are percentages of the group's main axis; the panel is uncontrolled after mount.

| Input         | Type     | Default |
| ------------- | -------- | ------- |
| `defaultSize` | `number` | `50`    |
| `minSize`     | `number` | `10`    |
| `maxSize`     | `number` | `100`   |

### ResizableHandle

Attribute selector: `[uiResizableHandle]`. Renders `role="separator"` with drag and keyboard resize; Escape cancels an in-progress drag.

| Input       | Type      | Default          |
| ----------- | --------- | ---------------- |
| `withHandle` | `boolean` | `false`         |
| `ariaLabel`  | `string`  | `"Resize panels"` |
