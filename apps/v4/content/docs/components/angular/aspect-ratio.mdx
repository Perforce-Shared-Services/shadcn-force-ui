## Usage

```ts
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```html
<div uiAspectRatio [ratio]="16/9" class="overflow-hidden rounded-lg">
  <img src="..." alt="..." class="size-full object-cover" />
</div>
```

Uses the native CSS `aspect-ratio` property — no padding-bottom hack needed for modern browsers (Angular 20+ baseline).
