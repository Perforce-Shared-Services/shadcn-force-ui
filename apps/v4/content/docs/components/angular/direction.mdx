## Usage

```ts
import { DirectionProvider } from "@/components/ui/direction"
```

```html
<div uiDirectionProvider direction="rtl">
  ...
</div>
```

Apply `[uiDirectionProvider]` as close to the content root as the RTL/LTR boundary actually is. Descendant components that inject `Directionality` (all direction-aware Force UI components) resolve the closest provider, so a nested provider overrides the outer one for its own subtree only.

## LTR

Left-to-right — the default for every locale except RTL scripts.

## API Reference

See the [Angular CDK bidi](https://material.angular.io/cdk/bidi/api) documentation — `[uiDirectionProvider]` wraps CDK's `Dir` directive, and `injectDirection()` returns the ambient `Directionality`.
