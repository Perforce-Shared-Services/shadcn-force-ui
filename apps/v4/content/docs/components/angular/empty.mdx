## Usage

```ts
import { Empty, EmptyHeader, EmptyMedia, EmptyTitle, EmptyDescription, EmptyContent } from "@/components/ui/empty"
```

```html
<div uiEmpty>
  <div uiEmptyHeader>
    <div uiEmptyMedia variant="icon"><!-- icon --></div>
    <h3 uiEmptyTitle>No results</h3>
    <p uiEmptyDescription>Try adjusting your search.</p>
  </div>
  <div uiEmptyContent>
    <button uiButton>Create item</button>
  </div>
</div>
```

## API Reference

### EmptyMediaComponent

| Input     | Type                    | Default     |
| --------- | ----------------------- | ----------- |
| `variant` | `"default" \| "icon"`   | `"default"` |
| `class`   | `string`                | –           |

All other sub-components accept only `class`.
