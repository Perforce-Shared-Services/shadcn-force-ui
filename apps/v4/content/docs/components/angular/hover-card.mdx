## Usage

```ts showLineNumbers
import {
  HoverCardContent,
  HoverCardPortal,
  HoverCardPositioner,
  HoverCardRoot,
  HoverCardTrigger,
} from "@/components/ui/hover-card"
```

```html showLineNumbers
<div uiHoverCardRoot>
  <button uiButton variant="link" uiHoverCardTrigger type="button">Hover Here</button>
  <ng-template uiHoverCardPortal>
    <div uiHoverCardPositioner>
      <div uiHoverCardContent>
        The React Framework – created and maintained by @vercel.
      </div>
    </div>
  </ng-template>
</div>
```

Every part is an attribute selector on a native element, so the host keeps its
native semantics — Angular's idiomatic equivalent of React's `asChild`/`render`.

<Callout>
  radix-ng v1.x ships this primitive as **preview-card**
  (`@radix-ng/primitives/preview-card`) — the p4one-era `@radix-ng/primitives/hover-card`
  module no longer exists. The Force UI part names and behaviour are unchanged;
  only the underlying import differs.
</Callout>

## Composition

Use the following composition to build a `HoverCard`:

```text
HoverCardRoot (div)
├── HoverCardTrigger
└── HoverCardPortal (ng-template)
    └── HoverCardPositioner (div)
        └── HoverCardContent (div)
```

React folds Portal + positioning + Content into one `HoverCardContent` part;
the Angular anatomy splits it so the positioner carries the `side`, `align`,
and offset inputs.

## Trigger Delays

Use `delay` and `closeDelay` on the trigger to control when the card opens and
closes.

```html showLineNumbers
<button uiHoverCardTrigger [delay]="100" [closeDelay]="200" type="button">
  Hover
</button>
```

## Positioning

Use the `side` and `align` inputs on `HoverCardPositioner` to control
placement.

```html showLineNumbers
<div uiHoverCardPositioner side="top" align="start">
  <div uiHoverCardContent>Content</div>
</div>
```
