The `Item` component is a straightforward flex container that can house nearly any type of content. Use it to display a title, description, and actions. Group it with `ItemGroup` to create a list of items.

## Usage

```ts
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/ui/item"

@Component({
  selector: "app-example",
  standalone: true,
  imports: [
    Item,
    ItemMedia,
    ItemContent,
    ItemTitle,
    ItemDescription,
    ItemActions,
  ],
  templateUrl: "./example.component.html",
})
export class ExampleComponent {}
```

```html
<div uiItem>
  <div uiItemMedia variant="icon">
    <svg><!-- icon --></svg>
  </div>
  <div uiItemContent>
    <div uiItemTitle>Title</div>
    <p uiItemDescription>Description</p>
  </div>
  <div uiItemActions>
    <button uiButton>Action</button>
  </div>
</div>
```

Every part is an attribute selector, so the host element stays yours: put `uiItem` on an `<a>` to get a link row, on a `<div>` for a static one. That is the Angular equivalent of React's `asChild` / Vue's `as-child` — no extra input required.

## Composition

Use the following composition to build an `Item`:

```text
ItemGroup
└── Item
    ├── ItemHeader
    ├── ItemMedia
    ├── ItemContent
    │   ├── ItemTitle
    │   └── ItemDescription
    ├── ItemActions
    └── ItemFooter
```

## Item vs Field

Use `Field` if you need to display a form input such as a checkbox, input, radio, or select.

If you only need to display content such as a title, description, and actions, use `Item`.

<Callout>
  `Field` is not part of the Angular registry yet — it is in the Group A backlog
  in `packages/registry-angular/AGENT-PORTING-GUIDE.md`.
</Callout>

## API Reference

### Item

The row container. Selector: `[uiItem]` — put it on the element you want to render, e.g. a `<div>` or an `<a>`.

| Input     | Type                                | Default     |
| --------- | ----------------------------------- | ----------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size`    | `"default" \| "sm" \| "xs"`         | `"default"` |
| `class`   | `string`                            | –           |

### ItemGroup

Groups related items together. Selector: `[uiItemGroup]`. Renders with `role="list"`.

| Input   | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | –       |

```html
<div uiItemGroup>
  <div uiItem>…</div>
  <div uiItem>…</div>
</div>
```

### ItemSeparator

A horizontal separator between items in a group. Selector: `[uiItemSeparator]`.

| Input   | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | –       |

<Callout>
  Unlike React and Vue, `ItemSeparator` does not wrap the `Separator` component:
  Angular does not allow two components on one host element, so it carries the
  separator styling itself. `<div uiItemSeparator></div>` renders the same DOM
  as React's `<ItemSeparator />
  `. See `packages/registry-angular/DIVERGENCES.md` §item-1.
</Callout>

```html
<div uiItemGroup>
  <div uiItem>…</div>
  <div uiItemSeparator></div>
  <div uiItem>…</div>
</div>
```

### ItemMedia

Displays media content such as icons, images, or avatars. Selector: `[uiItemMedia]`.

| Input     | Type                             | Default     |
| --------- | -------------------------------- | ----------- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |
| `class`   | `string`                         | –           |

```html
<div uiItemMedia variant="icon">
  <svg><!-- icon --></svg>
</div>
```

```html
<div uiItemMedia variant="image">
  <img src="…" alt="…" />
</div>
```

### ItemContent

Wraps the title and description of the item. Selector: `[uiItemContent]`.

| Input   | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | –       |

```html
<div uiItemContent>
  <div uiItemTitle>Title</div>
  <p uiItemDescription>Description</p>
</div>
```

| ------- | -------- | ------- |
| `class` | `string` | –       |
