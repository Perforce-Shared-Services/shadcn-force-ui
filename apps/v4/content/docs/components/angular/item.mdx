The `Item` component is a straightforward flex container that can house nearly any type of content. Use it to display a title, description, and actions. Group it with the `ItemGroup` component to create a list of items.

## Usage

```ts showLineNumbers
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/ui/item"
```

```html showLineNumbers
<div uiItem>
  <div uiItemMedia variant="icon">
    <svg aria-hidden="true"><!-- icon --></svg>
  </div>
  <div uiItemContent>
    <div uiItemTitle>Title</div>
    <p uiItemDescription>Description</p>
  </div>
  <div uiItemActions>
    <button uiButton>Action</button>
  </div>
</div>
```

Use the attribute selectors (`[uiItem]`, `[uiItemMedia]`, …) on whatever host element fits the semantics. Hosting `[uiItem]` on an `<a>` gives a clickable row — the hover and focus states apply to the anchor element (Angular's idiomatic equivalent of React's `render` prop).

## Composition

Use the following composition to build an `Item`:

```text
ItemGroup
└── Item
    ├── ItemHeader
    ├── ItemMedia
    ├── ItemContent
    │   ├── ItemTitle
    │   └── ItemDescription
    ├── ItemActions
    └── ItemFooter
```

## Item vs Field

Use `Field` if you need to display a form input such as a checkbox, input, radio, or select.

If you only need to display content such as a title, description, and actions, use `Item`.

## API Reference

### Item

The main component for displaying content with media, title, description, and actions. Attribute selector: `[uiItem]`.

| Input     | Type                                | Default     |
| --------- | ----------------------------------- | ----------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size`    | `"default" \| "sm" \| "xs"`         | `"default"` |

To render the item as a link, host it on an `<a>` element instead of a `<div>` (equivalent of React's `render` prop).

### ItemGroup

A container that groups related items together with consistent styling. Attribute selector: `[uiItemGroup]`. Renders with `role="list"`.

```html
<div uiItemGroup>
  <div uiItem>...</div>
  <div uiItem>...</div>
</div>
```

### ItemSeparator

A separator between items in a group. Attribute selector: `[uiItemSeparator]`.

| Input         | Type                            | Default      |
| ------------- | ------------------------------- | ------------ |
| `orientation` | `"horizontal" \| "vertical"`    | `"horizontal"` |
| `decorative`  | `boolean`                       | `true`       |

```html
<div uiItemGroup>
  <div uiItem>...</div>
  <div uiItemSeparator></div>
  <div uiItem>...</div>
</div>
```

### ItemMedia

The leading icon, avatar, or image slot. Attribute selector: `[uiItemMedia]`.

| Input     | Type                                    | Default     |
| --------- | --------------------------------------- | ----------- |
| `variant` | `"default" \| "icon" \| "image"`        | `"default"` |

### ItemContent

The main content area of the item. Attribute selector: `[uiItemContent]`. No additional inputs.

### ItemTitle

The title of the item. Attribute selector: `[uiItemTitle]`. No additional inputs. Host it on a heading element when the row is a standalone card.

### ItemDescription

The description of the item. Attribute selector: `[uiItemDescription]`. No additional inputs.

### ItemActions

The container for action buttons at the end of the row. Attribute selector: `[uiItemActions]`. No additional inputs.

### ItemHeader

A full-width header above the item content. Attribute selector: `[uiItemHeader]`. No additional inputs.

### ItemFooter

A full-width footer below the item content. Attribute selector: `[uiItemFooter]`. No additional inputs.
