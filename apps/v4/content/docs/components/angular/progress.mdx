## Usage

```ts
import { Progress } from "@/components/ui/progress"
```

```html
<div uiProgress [value]="75" aria-label="Uploading (75%)"></div>
```

Always supply `aria-label` or `aria-labelledby` — the component cannot derive an accessible name from context. Pass `[value]="null"` for an indeterminate (pulsing) state.
