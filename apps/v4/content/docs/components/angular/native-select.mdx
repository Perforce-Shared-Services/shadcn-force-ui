## Usage

```ts showLineNumbers
import {
  NativeSelect,
  NativeSelectOptGroup,
  NativeSelectOption,
  NativeSelectWrapper,
} from "@/components/ui/native-select"
```

```html showLineNumbers
<div uiNativeSelectWrapper>
  <select uiNativeSelect>
    <option uiNativeSelectOption value="">Select a fruit</option>
    <option uiNativeSelectOption value="apple">Apple</option>
    <option uiNativeSelectOption value="banana">Banana</option>
    <option uiNativeSelectOption value="blueberry">Blueberry</option>
    <option uiNativeSelectOption value="pineapple">Pineapple</option>
  </select>
</div>
```

React renders the positioning wrapper and the `<select>` from one component.
An Angular attribute selector can't render markup outside its host, so the port
splits into `[uiNativeSelectWrapper]` (wrapper + decorative chevron) and
`select[uiNativeSelect]`. The native element stays the real host, so `ngModel`,
`formControlName`, `(change)`, and `[disabled]` all bind natively — Angular's
idiomatic equivalent of React's single-component API.

## Composition

### Simple

Options placed directly under the select (no optgroups).

```text
NativeSelectWrapper
└── NativeSelect (select)
    ├── NativeSelectOption
    ├── NativeSelectOption
    ├── NativeSelectOption
    └── NativeSelectOption
```

### With groups

Use `optgroup[uiNativeSelectOptGroup]` to organize options into categories.

```text
NativeSelectWrapper
└── NativeSelect (select)
    ├── NativeSelectOptGroup
    │   ├── NativeSelectOption
    │   └── NativeSelectOption
    └── NativeSelectOptGroup
        ├── NativeSelectOption
        └── NativeSelectOption
```

## Disabled

Add the native `disabled` attribute to the select to disable it. The wrapper's
`has-[select:disabled]:opacity-50` rule dims the field and chevron together.

## Invalid

Use `aria-invalid` on the select to show validation errors and the `data-invalid`
attribute to the `Field` component for styling.

## Native Select vs Select

- Use `NativeSelect` for native browser behavior, better performance, or mobile-optimized dropdowns.
- Use `Select` for custom styling, animations, or complex interactions.

## API Reference

### NativeSelect

The main select component applied via `select[uiNativeSelect]` on a native `<select>`.

```html
<select uiNativeSelect>
  <option uiNativeSelectOption value="option1">Option 1</option>
  <option uiNativeSelectOption value="option2">Option 2</option>
</select>
```

| Input   | Type                  | Default     |
| ------- | --------------------- | ----------- |
| `size`  | `"default" \| "sm"`   | `"default"` |
| `class` | `string`              | -           |

Note: `size` is styling-only (`data-size`). It is never bound to the native
`[attr.size]`, which would change the visible row count of the listbox.

### NativeSelectWrapper

Positioning wrapper with the decorative disclosure chevron. Applied via
`div[uiNativeSelectWrapper]`.

| Input   | Type                  | Default     |
| ------- | --------------------- | ----------- |
| `size`  | `"default" \| "sm"`   | `"default"` |
| `class` | `string`              | -           |

### NativeSelectOption

Represents an individual option within the select. Applied via
`option[uiNativeSelectOption]`; `value`/`disabled` are the native attributes.

| Input   | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

### NativeSelectOptGroup

Groups related options together for better organization. Applied via
`optgroup[uiNativeSelectOptGroup]`; `label` is the native attribute.

| Input   | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |
