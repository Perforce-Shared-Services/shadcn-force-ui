## Usage

```ts
import {
  PaginationComponent,
  PaginationContentComponent,
  PaginationEllipsisComponent,
  PaginationItemComponent,
  PaginationLinkComponent,
  PaginationNextComponent,
  PaginationPreviousComponent,
} from "@/components/ui/pagination"
```

```html
<nav uiPagination>
  <ul uiPaginationContent>
    <li uiPaginationItem><a uiPaginationPrevious href="#"></a></li>
    <li uiPaginationItem><a uiPaginationLink href="#">1</a></li>
    <li uiPaginationItem><a uiPaginationLink href="#" isActive>2</a></li>
    <li uiPaginationItem><span uiPaginationEllipsis></span></li>
    <li uiPaginationItem><a uiPaginationNext href="#"></a></li>
  </ul>
</nav>
```

The component is presentational only — it renders links, it does not own the current page. Bind `isActive` to your own page state and point each `href` (or `routerLink`) at the page it navigates to.

## Composition

```text
[uiPagination]
└── [uiPaginationContent]

        ├── [uiPaginationLink]
        ├── [uiPaginationPrevious]
```

## API Reference

### PaginationLinkComponent

| Input      | Type                                                                                 | Default  |
| ---------- | ------------------------------------------------------------------------------------ | -------- |
| `isActive` | `boolean`                                                                            | `false`  |
| `size`     | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"icon"` |
| `class`    | `string`                                                                             | –        |

`isActive` renders the link with the `outline` button variant and sets `aria-current="page"`; inactive links use `ghost`.

### PaginationPreviousComponent · PaginationNextComponent

| Input   | Type     | Default                 |
| ------- | -------- | ----------------------- |
| `text`  | `string` | `"Previous"` / `"Next"` |
| `class` | `string` | –                       |

Both render their own chevron icon and label, and carry `aria-label="Go to previous page"` / `"Go to next page"`. The label is hidden below the `sm` breakpoint; the `aria-label` keeps them announced.

### PaginationComponent · PaginationContentComponent · PaginationItemComponent · PaginationEllipsisComponent

| Input   | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | –       |

`PaginationEllipsisComponent` hides its icon from assistive technology and exposes a visually hidden “More pages” label instead.
