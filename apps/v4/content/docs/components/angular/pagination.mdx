## Usage

```ts showLineNumbers
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from "@/components/ui/pagination"
```

Write the attribute selectors on native elements — `<nav uiPagination>` for the landmark, `<ul uiPaginationContent>` for the page list, and an `<a uiPaginationLink>` per page. `isActive` marks the current page and sets `aria-current="page"`.

```html showLineNumbers
<nav uiPagination>
  <ul uiPaginationContent>
    <li uiPaginationItem><a uiPaginationPrevious href="#"></a></li>
    <li uiPaginationItem><a uiPaginationLink href="#">1</a></li>
    <li uiPaginationItem><a uiPaginationLink href="#" isActive>2</a></li>
    <li uiPaginationItem><span uiPaginationEllipsis></span></li>
    <li uiPaginationItem><a uiPaginationNext href="#"></a></li>
  </ul>
</nav>
```

## Composition

Use the following composition to build a `Pagination`:

```text
Pagination
└── PaginationContent
    ├── PaginationItem
    │   └── PaginationPrevious
    ├── PaginationItem
    │   └── PaginationLink
    ├── PaginationItem
    │   └── PaginationEllipsis
    └── PaginationItem
        └── PaginationNext
```

## API Reference

### PaginationComponent

Attribute selector: `nav[uiPagination]`.

| Prop | Type | Default |
|---|---|---|
| `aria-label` | `string` | `"pagination"` |
| `class` | `string \| undefined` | `undefined` |

### PaginationLinkComponent

Attribute selector: `[uiPaginationLink]`. Composes `buttonVariants`.

| Prop | Type | Default |
|---|---|---|
| `isActive` | `boolean` | `false` |
| `size` | `ButtonSize` | `"icon"` |
| `class` | `string \| undefined` | `undefined` |

### PaginationPreviousComponent / PaginationNextComponent

Attribute selectors: `a[uiPaginationPrevious]`, `a[uiPaginationNext]`.

| Prop | Type | Default |
|---|---|---|
| `text` | `string` | `"Previous"` / `"Next"` |
| `size` | `ButtonSize` | `"default"` |
| `aria-label` | `string` | `"Go to previous page"` / `"Go to next page"` |
| `class` | `string \| undefined` | `undefined` |
