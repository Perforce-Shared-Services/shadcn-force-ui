## Usage

```ts showLineNumbers
import { Marker, MarkerContent, MarkerIcon } from "@/components/ui/marker"
```

```html showLineNumbers
<div uiMarker>
  <span uiMarkerIcon><svg aria-hidden="true" /></span>
  <span uiMarkerContent>Explored 4 files</span>
</div>
```

Use the attribute selector `[uiMarker]` on a native `<div>`, `<a>`, or `<button>` element. This keeps the host element's native semantics — Angular's idiomatic equivalent of React's `render` composition.

## Composition

Use the following composition to build a marker:

```text
Marker
├── MarkerIcon
└── MarkerContent
```

## Features

- Inline marker, bordered row, and labeled separator variants
- Decorative icon slot that is hidden from assistive tech
- Anchor/button hosts via the attribute selector for link and button markers
- Pairs with the `shimmer` utility class for streaming status text
- Customizable styling through the `class` input on every part

## Variants

Use `variant` to switch between an inline marker, bordered row, and labeled separator.

<ComponentPreview framework="angular" name="marker-variants" previewClassName="h-auto" />

| Variant     | Description                                          |
| ----------- | ---------------------------------------------------- |
| `default`   | An inline marker for status, notes, and actions.     |
| `border`    | A default marker with a bottom border under the row. |
| `separator` | A centered label with divider lines on each side.    |

## Accessibility

### Status and Progress

A marker bound to a value that updates on its own (e.g. an auto-refreshing relative timestamp) should be wrapped in `role="status"` so changes are announced. The static primitive has no live-region behavior of its own.

### Decorative Icons

`[uiMarkerIcon]` is always decorative (`aria-hidden`). Never host `uiMarker` on an `<a>`/`<button>` with only an icon and no content — the host would have no accessible name (WCAG 4.1.2). Pair the icon with content, or add an explicit `aria-label` on the host.

## API Reference

Wraps no upstream primitive; all parts below are Force UI originals.

### Marker

Wrapper for the whole row. Host it on any element; its host keeps that element's semantics.

| Prop      | Type                                     | Default     |
| --------- | ---------------------------------------- | ----------- |
| `variant` | `"default" \| "separator" \| "border"`   | `"default"` |
| `class`   | `string \| undefined`                    | —           |

### MarkerIcon

Decorative icon container. Always rendered with `aria-hidden="true"`.

| Prop    | Type                  | Default |
| ------- | --------------------- | ------- |
| `class` | `string \| undefined` | —       |

### MarkerContent

Text content of the marker.

| Prop    | Type                  | Default |
| ------- | --------------------- | ------- |
| `class` | `string \| undefined` | —       |
