## Usage

```ts
import { LabelComponent } from "@/components/ui/label"
```

```html
<label uiLabel for="email">Your email address</label>
```

The attribute selector keeps the host as a native `<label>`, so the browser's implicit label–control association via `for`/`id` or nesting works for free (WCAG 1.3.1).
