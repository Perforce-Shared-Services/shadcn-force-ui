## About

The Angular `command` is built on the same behaviour as cmdk (the React
registry's foundation), reimplemented without a primitive library — there is no
radix-ng or CDK command primitive. Fuzzy filtering, keyboard navigation and the
highlight state live in a `CommandRootService` that ships with the component.

## Usage

```ts
import {
  Command,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
  CommandSeparator,
} from "@/components/ui/command"
```

```html
<div uiCommand>
  <div uiCommandInput placeholder="Type a command or search..."></div>
  <div uiCommandList>
    <div uiCommandEmpty>No results found.</div>
    <div uiCommandGroup heading="Suggestions">
      <div uiCommandItem>Calendar</div>
    </div>
    <div uiCommandSeparator></div>
  </div>
</div>
```

`[uiCommandInput]` must be applied to a container element (it renders its own
inner search input), and `[uiCommandShortcut]` renders right-aligned key hints.

## Composition

```txt
<div uiCommand>                       // owns keyboard nav + result announcer
├── <div uiCommandInput>              // container; renders InputGroup + combobox input
└── <div uiCommandList>               // role="listbox", scrollable
    ├── <div uiCommandEmpty>          // shows when a search yields nothing
    ├── <div uiCommandGroup>          // hideable cluster with heading
    │   └── <div uiCommandItem>       // role="option"; (select) output
    │       └── <span uiCommandShortcut />
    └── <div uiCommandSeparator>      // hides while searching
```

## Basic

Open the palette in a modal dialog via `<ui-command-dialog>` and provide its
content as a projected `<ng-template>` (dialog portals stamp content outside
the component view). Wrap the palette in `<div uiCommand>` inside the template —
the root carries the state all parts share.

## API Reference

Force UI original — the parts wrap no upstream primitive. Each part is an
Angular directive/component applied to a plain element:

| Part | Selector | Notes |
| --- | --- | --- |
| `Command` | `[uiCommand]` | Root; provides `CommandRootService`, owns ArrowUp/Down, Home/End, Enter |
| `CommandDialog` | `ui-command-dialog` | Modal wrapper; `[(uiOpen)]`, `title`, `description`, `showCloseButton` inputs |
| `CommandInput` | `[uiCommandInput]` | Container; `placeholder`, `disabled`, `aria-label`, `[(value)]` |
| `CommandList` | `[uiCommandList]` | `role="listbox"`; `aria-label` (default `"Suggestions"`) |
| `CommandEmpty` | `[uiCommandEmpty]` | Shown when a non-empty search yields no items |
| `CommandGroup` | `[uiCommandGroup]` | `heading` input; hides when empty after filtering |
| `CommandItem` | `[uiCommandItem]` | `value`, `keywords`, `disabled`, `checked`; `(select)` output |
| `CommandShortcut` | `[uiCommandShortcut]` | Decorative key hint (`aria-hidden`) |
| `CommandSeparator` | `[uiCommandSeparator]` | Hairline; hidden while searching |
