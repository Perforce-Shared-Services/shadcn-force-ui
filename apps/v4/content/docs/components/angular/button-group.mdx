## Usage

```ts
import {
  ButtonGroupComponent,
  ButtonGroupSeparatorComponent,
  ButtonGroupTextComponent,
} from "@/components/ui/button-group"
```

```html
<div uiButtonGroup>
  <button uiButton variant="outline">Archive</button>
  <div uiButtonGroupSeparator></div>
  <button uiButton variant="outline">Report</button>
</div>
```

Each part is an attribute selector, so the host element stays caller-controlled — Angular's idiomatic equivalent of React's `asChild`. `[uiButtonGroupText]` renders a non-interactive label segment, and `[uiButtonGroupSeparator]` renders a divider between segments.

```html
<div uiButtonGroup>
  <div uiButtonGroupText>https://</div>
  <input class="..." />
</div>
```

## Composition

```text
[uiButtonGroup]
├── [uiButtonGroupText]
├── [uiButtonGroupSeparator]
└── (buttons, inputs, nested [uiButtonGroup])
```
