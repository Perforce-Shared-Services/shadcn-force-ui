## Usage

```ts
import {
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
} from "@/components/ui/button-group"
```

```html
<div uiButtonGroup>
  <button uiButton>Button 1</button>
  <button uiButton>Button 2</button>
</div>
```

Use the `[uiButtonGroup]` attribute selector on a native `<div>`. Give the group an `aria-label` naming the set of related actions.

## Composition

Use the following composition to build a `ButtonGroup`:

```text
ButtonGroup
├── Button or Input
├── ButtonGroupSeparator
└── ButtonGroupText
```

## API Reference

### ButtonGroup

Container that groups related buttons together with consistent styling. Attribute selector: `[uiButtonGroup]`.

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `class`       | `string`                     | —              |

```html
<div uiButtonGroup orientation="vertical">
  <button uiButton>Button 1</button>
  <button uiButton>Button 2</button>
</div>
```

### ButtonGroupSeparator

Visually divides buttons within a group. Attribute selector: `[uiButtonGroupSeparator]`. Renders `role="separator"` unless `decorative` is set (the default), in which case the role is removed.

| Prop          | Type                         | Default      |
| ------------- | ---------------------------- | ------------ |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |
| `decorative`  | `boolean`                    | `true`       |

```html
<div uiButtonGroup>
  <button uiButton>Button 1</button>
  <div uiButtonGroupSeparator></div>
  <button uiButton>Button 2</button>
</div>
```

### ButtonGroupText

Displays static text within a button group. Attribute selector: `[uiButtonGroupText]` on any host element. React's `asChild` prop has no Angular equivalent — write the desired host element directly:

```html
<div uiButtonGroup>
  <label uiButtonGroupText for="volume">Volume</label>
  <input id="volume" />
</div>
```
