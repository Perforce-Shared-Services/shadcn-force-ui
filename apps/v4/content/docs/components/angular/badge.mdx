## Usage

```ts
import { BadgeComponent } from "@/components/ui/badge"
```

```html
<span uiBadge variant="success">Synced</span>
```

## Variants

Use the `variant` input to change the variant of the badge.

## With Icon

Project an inline `<svg>` tagged `data-icon="inline-start"` or `"inline-end"`.

<ComponentPreview framework="angular" name="badge-icon" />

## With Spinner

You can render a spinner inside the badge. Remember to add the `data-icon="inline-start"` or `data-icon="inline-end"` attribute to the spinner.

<ComponentPreview framework="angular" name="badge-spinner" />

## Link

Use the badge on a native `<a>` element — the attribute selector rides the anchor directly, Angular's idiomatic equivalent of React's `render` prop.

<ComponentPreview framework="angular" name="badge-link" />

### Solid Status Variants

Use solid variants for maximum-attention states like critical counts or overdue flags.

<ComponentPreview framework="angular" name="badge-solid" />

## Custom Colors

You can customize the colors of a badge by adding custom classes such as `bg-green-50 dark:bg-green-800` to the badge element.
