## Usage

```ts
import { Slider } from "@/components/ui/slider"
```

```html
<div uiSlider [defaultValue]="[33]" [max]="100" [step]="1"></div>
```

The host element carries the `uiSlider` attribute. The value is a `number[]` model — one entry per thumb; pass two values for a range slider and bind two-way with `[(value)]`.

```ts
@Component({
  imports: [SliderComponent],
  template: `<div uiSlider [(value)]="volume" aria-label="Volume"></div>`,
})
```
