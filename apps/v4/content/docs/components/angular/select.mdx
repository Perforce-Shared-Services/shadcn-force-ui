## Usage

```ts
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"
```

```html
<div uiSelect defaultValue="apple">
  <button uiSelectTrigger class="w-full max-w-48">
    <span uiSelectValue placeholder="Select a fruit"></span>
  </button>
  <ng-template uiSelectPortal>
    <div uiSelectPositioner>
      <div uiSelectContent>
        <div uiSelectGroup>
          <div uiSelectLabel>Fruits</div>
          <div uiSelectItem value="apple">Apple</div>
          <div uiSelectItem value="banana">Banana</div>
        </div>
      </div>
    </div>
  </ng-template>
</div>
```

Selection is uncontrolled by default (`defaultValue`). For the controlled form, bind `[uiValue]` and listen to `(uiValueChange)` on the `[uiSelect]` root.

## Composition

Use the following composition to build a `Select`:

```text
uiSelect
├── uiSelectTrigger
│   └── uiSelectValue
└── ng-template uiSelectPortal
    └── uiSelectPositioner
        └── uiSelectContent
            ├── uiSelectGroup
            │   ├── uiSelectLabel
            │   └── uiSelectItem
            ├── uiSelectSeparator
            └── uiSelectGroup
                ├── uiSelectLabel
                └── uiSelectItem
```

The React `SelectPortal` / `SelectPositioner` fold into two explicit Angular nodes: the portal `<ng-template>` and a thin positioner wrapper inside it. Placement is automatic with collision flipping.

<Callout>
  Unlike most Force UI Angular parts, `SelectTrigger`, `SelectValue`, `SelectContent` and `SelectItem` are components with templates (chevron, check indicator), so they render on their own host element rather than purely as attribute markers.
</Callout>

## Invalid

Add the `data-invalid` attribute to the `Field` component and the `aria-invalid` attribute to the `SelectTrigger` component to show an error state.

```html showLineNumbers /data-invalid/ /aria-invalid/
<div uiField data-invalid>
  <label uiFieldLabel>Fruit</label>
  <div uiSelect>
    <button uiSelectTrigger aria-invalid="true" class="w-full">
      <span uiSelectValue placeholder="Select a fruit"></span>
    </button>
    <ng-template uiSelectPortal>
      <div uiSelectPositioner>
        <div uiSelectContent>
          <div uiSelectItem value="apple">Apple</div>
          <div uiSelectItem value="banana">Banana</div>
        </div>
      </div>
    </ng-template>
  </div>
</div>
```
