## About

Unlike the React, Vue, and Svelte ports — which each wrap a framework-specific headless package (`input-otp`, `vue-input-otp`, `bits-ui`) — the Angular component is hand-rolled: no equivalent primitive ships for Angular. It keeps the same contract: one real, invisible `<input>` owns focus, keyboard, paste, mobile IME, and screen-reader behaviour, and the slots are decorative cells that react to its state. See `DIVERGENCES.md` in the Angular registry for the details.

## Usage

```ts
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
  REGEXP_ONLY_DIGITS,
} from "@/components/ui/input-otp"
```

```html
<div uiInputOtp aria-label="One-time password" [maxLength]="6" [(value)]="code">
  <div uiInputOtpGroup>
    <div uiInputOtpSlot [index]="0"></div>
    <div uiInputOtpSlot [index]="1"></div>
    <div uiInputOtpSlot [index]="2"></div>
  </div>
  <div uiInputOtpSeparator></div>
  <div uiInputOtpGroup>
    <div uiInputOtpSlot [index]="3"></div>
    <div uiInputOtpSlot [index]="4"></div>
    <div uiInputOtpSlot [index]="5"></div>
  </div>
</div>
```

Give the control an accessible name with either `aria-label` or a real `<label for>` paired with `id` — `id`, `name`, `pattern`, `required`, `disabled`, and the `aria-*` inputs are all forwarded to the real `<input>`, never to the container.

## Composition

```text
[uiInputOtp]
├── [uiInputOtpGroup]
│   └── [uiInputOtpSlot] [index]
├── [uiInputOtpSeparator]
└── [uiInputOtpGroup]
    └── [uiInputOtpSlot] [index]
```

## API Reference

### InputOTPComponent

| Input              | Type      | Default |
| ------------------ | --------- | ------- |
| `value`            | `string`  | `""`    |
| `maxLength`        | `number`  | `6`     |
| `pattern`          | `string`  | –       |
| `disabled`         | `boolean` | `false` |
| `required`         | `boolean` | `false` |
| `name`             | `string`  | –       |
| `id`               | `string`  | –       |
| `aria-label`       | `string`  | –       |
| `aria-invalid`     | `boolean` | `false` |
| `aria-describedby` | `string`  | –       |
| `class`            | `string`  | –       |

| Output     | Type     | Description                                       |
| ---------- | -------- | ------------------------------------------------- |
| `complete` | `string` | Emits once `value` reaches `maxLength` characters |

`value` is a model input: bind one-way with `[value]` or two-way with `[(value)]`.

### InputOTPSlotComponent

| Input   | Type     | Default    |
| ------- | -------- | ---------- |
| `index` | `number` | – required |
| `class` | `string` | –          |

### InputOTPGroupComponent

| Input   | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | –       |

### InputOTPSeparatorComponent

Takes no inputs — a decorative `role="separator"` divider between groups.

### Constants

| Name                           | Value            |
| ------------------------------ | ---------------- |
| `REGEXP_ONLY_DIGITS`           | `^\d+$`          |
| `REGEXP_ONLY_CHARS`            | `^[a-zA-Z]+$`    |
| `REGEXP_ONLY_DIGITS_AND_CHARS` | `^[a-zA-Z0-9]+$` |
