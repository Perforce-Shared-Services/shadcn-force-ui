## About

Input OTP follows the API of the React [input-otp](https://github.com/guilherme_rodz/input-otp) component, implemented natively for Angular — no third-party OTP package required.

<Callout>
  The Angular implementation stretches one real `<input>` over the full slot
  row instead of pixel-aligning the caret under each slot. The public API,
  keyboard/paste/mobile IME behaviour, and accessibility contract are the
  same.
</Callout>

## Composition

- `InputOTP` — the root container. Renders one real, invisible `<input>` stretched over the slot row; hosts the groups, slots, and separators.
  - `InputOTPGroup` — a visual cluster of slots sharing a rounded frame.
    - `InputOTPSlot` — one character cell; purely decorative, reacts to shared state.
  - `InputOTPSeparator` — decorative divider between groups.

## API Reference

The root forwards `id`, `name`, `required`, `pattern`, `disabled`, `aria-label`, `aria-invalid`, and `aria-describedby` to the real `<input>` (not the container), matching the upstream package's prop routing — pair a `<label for>` with `id` the same way you would for Input.

| Part                 | Selector                  | Key inputs                                                        |
| -------------------- | ------------------------- | ----------------------------------------------------------------- |
| `InputOTP`           | `[uiInputOtp]`            | `[(value)]`, `maxLength`, `pattern`, `disabled`, `required`, `id` |
| `InputOTPGroup`      | `[uiInputOtpGroup]`       | `class`                                                           |
| `InputOTPSlot`       | `[uiInputOtpSlot]`        | `[index]` (required), plain `aria-invalid` attribute              |
| `InputOTPSeparator`  | `[uiInputOtpSeparator]`   | —                                                                 |

Also exported: `REGEXP_ONLY_DIGITS`, `REGEXP_ONLY_CHARS`, `REGEXP_ONLY_DIGITS_AND_CHARS`.
