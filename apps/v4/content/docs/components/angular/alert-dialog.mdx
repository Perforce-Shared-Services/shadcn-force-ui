## Usage

```ts
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog"
```

```html
<div uiAlertDialog>
  <button uiButton variant="outline" uiAlertDialogTrigger>Show Dialog</button>
  <ng-template uiAlertDialogPortal>
    <div uiAlertDialogOverlay></div>
    <div uiAlertDialogContent>…</div>
  </ng-template>
</div>
```

An alert dialog has no close (X) button and cannot be dismissed by clicking the backdrop — the user must choose a footer action. Escape still closes, matching the React behaviour.

## Composition

Use the following composition to build an `AlertDialog`:

```text
AlertDialog
├── AlertDialogTrigger
└── ng-template (uiAlertDialogPortal)
    ├── AlertDialogOverlay
    └── AlertDialogContent
        ├── AlertDialogHeader
        │   ├── AlertDialogMedia
        │   ├── AlertDialogTitle
        │   └── AlertDialogDescription
        └── AlertDialogFooter
            ├── AlertDialogCancel
            └── AlertDialogAction
```

## API Reference

### size

Use the `size` input on the `AlertDialogContent` component to control the size of the alert dialog. It accepts the following values:

| Input  | Type                | Default     |
| ------ | ------------------- | ----------- |
| `size` | `"default" \| "sm"` | `"default"` |

For more information about the other parts and their inputs, see the [radix-ng Alert Dialog](https://www.radix-ng.com/primitives/alert-dialog) documentation.
