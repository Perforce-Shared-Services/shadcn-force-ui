## Usage

```ts showLineNumbers
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet"
```

```html showLineNumbers
<div uiSheet>
  <button uiButton uiSheetTrigger>Open</button>
  <ng-template uiSheetPortal>
    <div uiSheetOverlay></div>
    <div uiSheetContent side="right">
      <div uiSheetHeader>
        <h2 uiSheetTitle>Edit profile</h2>
        <p uiSheetDescription>Make changes to your profile here.</p>
      </div>
      <div uiSheetFooter>
        <button uiButton type="submit">Save changes</button>
        <button uiButton variant="outline" uiSheetClose>Close</button>
      </div>
    </div>
  </ng-template>
</div>
```

The sheet body lives in an `<ng-template uiSheetPortal>` that portals to `document.body` while open. The overlay is composed explicitly (`<div uiSheetOverlay>`) rather than rendered implicitly — Angular's declarative equivalent of React's built-in `SheetPortal` + `SheetOverlay`.

All directives use attribute selectors on native elements (`button[uiSheetTrigger]`, `h2[uiSheetTitle]`, …) so native semantics are preserved — Angular's idiomatic equivalent of React's `asChild`.

<Callout>
  The Angular sheet uses radix-ng v1.x's declarative dialog API (`RdxDialogRoot`/`Trigger`/`Portal`/`Popup`) instead of p4one's CDK-based `@angular/cdk/dialog` port. Behaviour (focus trap, scroll lock, Escape, outside-click dismissal, aria wiring) is provided by radix-ng.
</Callout>

## Composition

Use the following composition to build a `Sheet`:

```text
Sheet
├── SheetTrigger
└── SheetPortal
    ├── SheetOverlay
    └── SheetContent
        ├── SheetHeader
        │   ├── SheetTitle
        │   └── SheetDescription
        └── SheetFooter
```

## Side

Use the `side` input to control which edge the sheet slides in from. Defaults to `right`.

## No Close Button

Set `[showCloseButton]="false"` to hide the corner close button. Provide an explicit dismiss action in the footer, or rely on Escape / clicking outside.

## RTL

Sheets follow the document or element `dir`. In RTL layouts the sheet slides from the left edge — pass `side="left"` alongside `dir="rtl"`.

<Callout>
The Angular RTL demo renders the Arabic state statically; the React version cycles en/ar/he via a language switcher. The rendered behaviour is the same.
</Callout>
