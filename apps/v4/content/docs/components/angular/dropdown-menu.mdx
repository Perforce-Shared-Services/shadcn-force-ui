## Usage

```ts
import {
  DropdownMenuCheckboxItem,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuRadioGroup,
  DropdownMenuRadioItem,
  DropdownMenuRoot,
  DropdownMenuSeparator,
  DropdownMenuShortcut,
  DropdownMenuSub,
  DropdownMenuSubContent,
  DropdownMenuSubTrigger,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"
```

```html
<div uiDropdownMenuRoot>
  <button uiButton variant="outline" uiDropdownMenuTrigger>Open</button>
  <div uiDropdownMenuContent>
    <button uiDropdownMenuItem>Profile</button>
    <button uiDropdownMenuItem>Billing</button>
  </div>
</div>
```

Every part is an attribute selector on a native element, so the host keeps its
native semantics — Angular's idiomatic equivalent of React's `asChild`/`render`.

The React `DropdownMenu` root maps to `<div uiDropdownMenuRoot>` and
`DropdownMenuPortal` has no Angular equivalent — the content's positioner
renders in place. Items are native `<button>`s carrying `uiDropdownMenuItem`;
activation is exposed through `(onSelect)`.

## Composition

Use the following composition to build a `Dropdown Menu`:

```text
DropdownMenuRoot
├── DropdownMenuTrigger
└── DropdownMenuContent
    ├── DropdownMenuGroup
    │   ├── DropdownMenuLabel
    │   ├── DropdownMenuItem
    │   │   └── DropdownMenuShortcut
    │   ├── DropdownMenuCheckboxItem
    │   └── DropdownMenuRadioGroup
    │       └── DropdownMenuRadioItem
    └── DropdownMenuSub
        ├── DropdownMenuSubTrigger
        └── DropdownMenuSubContent
```

## Shortcuts

Add a `<span uiDropdownMenuShortcut>` inside an item to hint its keyboard
shortcut. It is aria-hidden — the item's own text remains the accessible name.

<ComponentPreview framework="angular" name="dropdown-menu-shortcuts" />

## Icons

Project any inline SVG as a leading icon; the item styles size and colour it.
Destructive items tint their icon automatically via `variant="destructive"`.

<ComponentPreview framework="angular" name="dropdown-menu-icons" />

## Checkboxes

Two-way bind each checkbox item with `[(checked)]`. The menu stays open across
toggles so several options can be changed in one pass.
