## Usage

```ts
import {
  CardComponent, CardHeaderComponent, CardTitleComponent,
  CardDescriptionComponent, CardActionComponent,
  CardContentComponent, CardFooterComponent,
} from "@/components/ui/card"
```

```html
<div uiCard>
  <div uiCardHeader>
    <h3 uiCardTitle>Title</h3>
    <p uiCardDescription>Description</p>
    <div uiCardAction><!-- action --></div>
  </div>
  <div uiCardContent><!-- content --></div>
  <div uiCardFooter><!-- footer --></div>
</div>
```

Use a real heading element for `uiCardTitle` so the page heading hierarchy is correct for screen readers.

## Composition

```text
[uiCard]
├── [uiCardHeader]
│   ├── [uiCardTitle]
│   ├── [uiCardDescription]
│   └── [uiCardAction]
├── [uiCardContent]
└── [uiCardFooter]
```
