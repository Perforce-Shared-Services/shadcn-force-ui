## Usage

```ts
import { ButtonComponent } from "@/components/ui/button"
```

```html
<button uiButton variant="outline">Button</button>
```

Use the attribute selector `[uiButton]` on a native `<button>` or `<a>` element. This keeps the host element's native semantics — Angular's idiomatic equivalent of React's `asChild`.

```ts
@Component({
  imports: [ButtonComponent],
  template: `<button uiButton>Click me</button>`,
})
```

## Disabled on anchors

On `<a uiButton>`, the native `disabled` attribute has no effect. The component automatically applies `aria-disabled="true"`, `tabindex="-1"`, and a click guard instead (WCAG 2.1.1 / 4.1.2).

```html
<a uiButton variant="link" href="/path" [disabled]="true">Disabled link</a>
```

## API Reference

### ButtonComponent

| Input       | Type                                                                                    | Default     |
| ----------- | --------------------------------------------------------------------------------------- | ----------- |
| `variant`   | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"`          | `"default"` |
| `size`      | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
| `disabled`  | `boolean`                                                                               | `false`     |
| `loading`   | `boolean`                                                                               | `false`     |
| `class`     | `string`                                                                                | –           |
