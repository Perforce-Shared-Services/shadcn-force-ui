## Usage

```ts
import {
  Bubble,
  BubbleContent,
  BubbleGroup,
  BubbleReactions,
} from "@/components/ui/bubble"
```

```html
<div uiBubble variant="muted">
  <div uiBubbleContent>Can you tell me what's the issue?</div>
</div>
```

All parts are attribute selectors that decorate the host element you write — Angular's idiomatic equivalent of React's `asChild`. Put `<div uiBubbleContent>` on a `<button>` or `<a>` to make the bubble itself clickable; it picks up the focus-visible ring automatically.

`Bubble`'s `variant` colors every slotted `BubbleContent` via descendant CSS tokens — set the variant on the outer `Bubble`, not on `BubbleContent`.

## Composition

```
BubbleGroup
└── Bubble (variant, align)
    ├── BubbleContent
    └── BubbleReactions (side, align)
        └── emoji spans or Button / Tooltip / Popover
```

## Variants

Seven visual variants driven by the `variant` input: `default`, `secondary`, `muted`, `tinted`, `outline`, `ghost`, and `destructive`.

<ComponentPreview framework="angular" name="bubble-variants" />

## Alignment

Use `align="end"` for outgoing (user) messages; `start` is the default for incoming messages.

<ComponentPreview framework="angular" name="bubble-alignment" />

## Grouping

`BubbleGroup` stacks consecutive bubbles from the same speaker with consistent spacing.

<ComponentPreview framework="angular" name="bubble-group-demo" />

## Reactions

`BubbleReactions` is an absolutely-positioned pill anchored to a corner of its bubble. Use `side="top" | "bottom"` and `align="start" | "end"`.

<ComponentPreview framework="angular" name="bubble-reactions" />

When the reaction content is a bare emoji or count, always add `role="img"` and an `aria-label` describing the reactions (WCAG 1.1.1).
