## Usage

```ts
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
  ComboboxList,
} from "@/components/ui/combobox"
```

```html
<div uiCombobox [(value)]="framework">
  <div uiComboboxInput placeholder="Select a framework" />
  <ng-template uiComboboxContent>
    <div uiComboboxEmpty>No items found.</div>
    <div uiComboboxList>
      @for (item of frameworks; track item) {
        <div uiComboboxItem [value]="item">{{ item }}</div>
      }
    </div>
  </ng-template>
</div>
```

The popup is an anchored, non-modal CDK overlay: DOM focus stays in the input while the listbox is driven by `aria-activedescendant`, so closing with Escape leaves focus on the field. Items are iterated by the caller (`@for`) — the React render-prop `items` API becomes plain template loops.

## Composition

### Simple

A single-line input and a flat list (see [Basic](#basic)).

```text
Combobox
├── ComboboxInput
└── ComboboxContent
    ├── ComboboxEmpty
    └── ComboboxList
        ├── ComboboxItem
        └── ComboboxItem
```

### With chips

Multi-select with `multiple`, chips, and a chips input (see [Multiple](#multiple)).

```text
Combobox
├── ComboboxChips
│   ├── ComboboxChip
│   └── ComboboxChipsInput
└── ComboboxContent
    ├── ComboboxEmpty
    └── ComboboxList
        └── ComboboxItem
```

### With groups and collection

Nested items per group using `ComboboxCollection` inside each `ComboboxGroup`, with a separator between groups (see [Groups](#groups)).

```text
Combobox
├── ComboboxInput
└── ComboboxContent
    ├── ComboboxEmpty
    └── ComboboxList
        ├── ComboboxGroup
        │   ├── ComboboxLabel
        │   └── ComboboxCollection
        │       └── ComboboxItem
        └── ComboboxGroup
            ├── ComboboxLabel
            └── ComboboxCollection
                └── ComboboxItem
```

## Custom Items

Give object items an explicit `label` (used for display and filtering).

```html
<div uiComboboxItem [value]="country" [label]="country.label">…</div>
```

## Multiple Selection

Use `[multiple]="true"` with chips for multi-select behavior. The chips container anchors the popup, so it tracks the box as it grows.

```html
<div uiCombobox [(value)]="value" [multiple]="true">
  <div uiComboboxChips>
    @for (v of value(); track v) {
      <span uiComboboxChip [value]="v">{{ v }}</span>
    }
    <input uiComboboxChipsInput placeholder="Add framework" />
  </div>
  <ng-template uiComboboxContent>…</ng-template>
</div>
```

## API Reference

<Callout>
There is no upstream Angular combobox primitive — like `command`, the selection/filter store is reimplemented in `ComboboxRootService`. The parts below wrap native elements directly.
</Callout>

### Combobox

Root container. Provides the selection/filter store to all descendants.

| Prop | Type | Default |
| --- | --- | --- |
| `[(value)]` | `unknown \| unknown[]` | `null` |
| `[(open)]` | `boolean` | `false` |
| `selectionMode` | `"none" \| "single" \| "multiple"` | `"single"` |
| `multiple` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `readOnly` | `boolean` | `false` |
| `loopFocus` | `boolean` | `true` |
| `openOnInputClick` | `boolean` | `true` |
| `autoHighlight` | `boolean \| "always"` | `false` |
| `limit` | `number` | `-1` |
| `shouldFilter` | `boolean` | `true` |

### ComboboxInput

The search/trigger field, composed from `InputGroup`. Renders its own chevron trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `placeholder` | `string` | `""` |
| `showTrigger` | `boolean` | `true` |
| `showClear` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `aria-invalid` | `boolean` | `false` |
| `aria-label` | `string` | — |

### ComboboxContent

Anchored non-modal popup applied to an `<ng-template>`; positions against the input or the chips container.

| Prop | Type | Default |
| --- | --- | --- |
| `side` | `"top" \| "bottom"` | `"bottom"` |

### ComboboxItem

One selectable option row with a trailing check indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `unknown` | `null` |
| `label` | `string` | text content |
| `disabled` | `boolean` | `false` |

### ComboboxChips / ComboboxChip / ComboboxChipsInput

Multi-select chip container (also the popup anchor), one removable chip per selected value, and the inline text input.

| Prop | Type | Default |
| --- | --- | --- |
| `showRemove` (chip) | `boolean` | `true` |
| `placeholder` (chips input) | `string` | `""` |

### ComboboxGroup / ComboboxLabel

A labelled cluster of items that hides entirely when filtered empty; the label registers itself for `aria-labelledby`.
