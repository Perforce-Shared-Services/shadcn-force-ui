## Usage

```ts showLineNumbers
import { ChartBarComponent } from "@/components/ui/chart"
```

```html showLineNumbers
<div uiChartBar [data]="data" />
```

The Angular port renders chart types through `ngx-charts` — recharts is a React renderer with no Angular equivalent. `ChartContainer`, `ChartTooltipContent` and `ChartLegendContent` keep the registry's API (config-driven `--color-{key}` variables, indicator variants), while `<div uiChartBar>` replaces the recharts `<BarChart>`/`<Bar>` composition.

## Composition

```
<div uiChartBar>            ← chart type + flags (grid/axis/legend/tooltip)
├── div[uiChartContainer]   ← sizing box + per-series CSS variables
│   └── ngx-charts bar      ← SVG renderer (internal)
├── div[uiChartLegendContent]
└── div[uiChartTooltipContent]  ← rendered inside ngx-charts' tooltip template
```

## API Reference

### ChartBarComponent

Attribute selector: `div[uiChartBar]`.

| Prop | Type | Default |
| --- | --- | --- |
| `data` | `ChartBarDatum[]` | — |
| `colorMapping` | `ChartConfig` | `undefined` |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
| `stacked` | `boolean` | `false` |
| `color` | `string` | `undefined` |
| `seriesLabel` | `string` | `"Value"` |
| `showGrid` | `boolean` | `true` |
| `showXAxis` | `boolean` | `true` |
| `showYAxis` | `boolean` | `false` |
| `legend` | `boolean` | `true` |
| `tooltip` | `boolean` | `true` |

### ChartContainerComponent

Attribute selector: `div[uiChartContainer]`.

| Prop | Type | Default |
| --- | --- | --- |
| `config` | `ChartConfig` | — |
| `id` | `string` | auto-generated |
