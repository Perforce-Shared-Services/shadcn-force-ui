## Usage

Render the toaster once (e.g. in your app shell), then call `toast()` from anywhere.

```ts
import { Toaster, toast } from "@/components/ui/sonner"
```

```html
<ui-sonner-toaster />
```

```ts
import { toast } from "ngx-sonner"

toast("Version saved")
```

The component is an element selector (`ui-sonner-toaster`) because it is a singleton shell with no host semantics of its own — unlike the attribute-selector parts elsewhere in this registry.

## API Reference

Wraps [`ngx-sonner`](https://github.com/emilkowalski/sonner) (the Angular port of `sonner`). See the upstream documentation for the full `toast()` call API; the props below are what Force UI adds or overrides on `<ui-sonner-toaster />`.

### Toaster

| Prop | Type | Default |
| --- | --- | --- |
| `theme` | `"light" \| "dark" \| "system"` | `"light"` |
| `position` | `"top-left" \| "top-center" \| "top-right" \| "bottom-left" \| "bottom-center" \| "bottom-right"` | `"bottom-right"` |
| `richColors` | `boolean` | `false` |
| `closeButton` | `boolean` | `true` |
| `expand` | `boolean` | `false` |
| `duration` | `number` | `4000` |
| `visibleToasts` | `number` | `3` |
| `offset` | `string \| number \| null` | `null` |
| `invert` | `boolean` | `false` |
| `style` | `Record<string, string>` | Force token map (merged) |
| `toastOptions` | `ToastOptions` | Force class map (merged) |
